# Portafolio | Cecilia Saldivar

Portafolio personal de una desarrolladora Full-Stack Junior, construido a partir de un diseño en Figma. Presenta mi perfil, habilidades, proyectos destacados y enlaces de contacto.

**[Ver sitio en GitHub Pages](https://ceci1208.github.io/web_project_portfolio_es/)**

## Tecnologías y herramientas

- **HTML5:** estructura semántica con secciones, navegación y tarjetas de proyectos.
- **CSS3:** maquetación con Flexbox y Grid, variables de color, degradados, transiciones y clases con nomenclatura BEM.
- **JavaScript:** actualización automática del año del footer y prevención del salto de página en enlaces provisionales (`href="#"`).
- **SVG:** iconos reutilizables mediante `symbol` y `use`.
- **Google Fonts:** tipografías Archivo Black y Open Sans.
- **Figma, Git y GitHub Pages:** referencia visual, control de versiones y publicación del sitio.

El sitio utiliza HTML, CSS y JavaScript sin frameworks ni dependencias de instalación.

## Diseño y funcionalidades

- Diseño adaptable a escritorio, tablet y móvil, con referencias de 1440, 768 y 320 px.
- Media queries a 900 y 600 px para ajustar tipografía, imágenes, iconos y distribución.
- Tarjetas con enlaces a la demo y al repositorio alineados al fondo, y sombras degradadas sobre las imágenes.
- Efectos hover y etiquetas en los iconos del perfil, también disponibles al enfocarlos con el teclado.
- Navegación interna hacia el contacto, etiquetas accesibles y respeto por la preferencia de movimiento reducido.
